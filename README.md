# Minecraft Trapped Chest Loot Plugin

Trap Chest Loot is a Minecraft server plugin that adds one-time weapon, ammunition, and mineral loot to trapped chests. When a player opens an unlooted trapped chest, it receives a crossbow named Combat Rifle, arrow ammunition, and either amethyst shards or raw gold; a bonus stack of ammunition may also appear.

## Install

1. Use a Paper server running Minecraft 1.21 or later and Java 21.
2. Build the plugin with Maven using `mvn package`.
3. Copy the generated `plugin.jar` from the `target` directory into the server’s `plugins` directory.
4. Restart the server.

## Use

1. Place a trapped chest in the world.
2. Open it to generate its loot the first time.
3. Loot the crossbow, arrows, and mineral items from the chest. Its loot is not generated again after the first opening.
